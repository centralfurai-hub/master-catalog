Master Catalog × Supabase
Hubungkan ke database Supabase Anda
Cara setup: Buka supabase.com → buat project → copy Project URL dan anon key → paste di form ini dan klik Hubungkan
📋 SQL — jalankan sekali di Supabase SQL Editor
Buka Supabase → SQL Editor → paste semua SQL di bawah → klik Run. Sudah termasuk setup tabel + bucket foto.
-- TABEL CREATE TABLE IF NOT EXISTS mc_products ( id TEXT PRIMARY KEY, name TEXT NOT NULL, alias TEXT, harga BIGINT DEFAULT 0, kategori TEXT, keterangan TEXT, divisi JSONB DEFAULT '{}', img TEXT, created_at TEXT, updated_at TEXT ); CREATE TABLE IF NOT EXISTS mc_categories (id SERIAL PRIMARY KEY, name TEXT UNIQUE NOT NULL); CREATE TABLE IF NOT EXISTS mc_log (id SERIAL PRIMARY KEY, msg TEXT, type TEXT, username TEXT, created_at TEXT); ALTER TABLE mc_products DISABLE ROW LEVEL SECURITY; ALTER TABLE mc_categories DISABLE ROW LEVEL SECURITY; ALTER TABLE mc_log DISABLE ROW LEVEL SECURITY; -- STORAGE BUCKET FOTO INSERT INTO storage.buckets (id, name, public) VALUES ('mc-photos', 'mc-photos', true) ON CONFLICT (id) DO UPDATE SET public = true; -- POLICY: izinkan upload foto (anon) DROP POLICY IF EXISTS "mc_photos_insert" ON storage.objects; CREATE POLICY "mc_photos_insert" ON storage.objects FOR INSERT TO anon WITH CHECK (bucket_id = 'mc-photos'); -- POLICY: izinkan lihat foto (public) DROP POLICY IF EXISTS "mc_photos_select" ON storage.objects; CREATE POLICY "mc_photos_select" ON storage.objects FOR SELECT TO anon USING (bucket_id = 'mc-photos'); -- POLICY: izinkan update/ganti foto (anon) DROP POLICY IF EXISTS "mc_photos_update" ON storage.objects; CREATE POLICY "mc_photos_update" ON storage.objects FOR UPDATE TO anon USING (bucket_id = 'mc-photos');

Upload file xlsx hasil export Accurate langsung tanpa perlu diubah. Sistem otomatis mendeteksi format:
 • Format Baru — header: Nama Barang · Stok · Harga Jual · Kategori Barang
 • Format Lama Accurate — laporan multi-level dengan kategori di baris terpisah
